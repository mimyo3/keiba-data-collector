# Multi-Agent System

A multi-agent system with conductor, coder, researcher, tester, and adversary agents.

## Structure

- `src/` - Source code
- `tests/` - Test files
- `docs/` - Documentation
- `config/` - Configuration files

## Agents

1. Conductor - Orchestrates the system
2. Coder - Writes code
3. Researcher - Conducts research
4. Tester - Writes tests
5. Adversary - Challenges the system

## Getting Started

```bash
npm install
npm start
```
